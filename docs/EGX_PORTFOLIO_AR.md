# مستشار المحفظة المصرية

هذه الطبقة تحول المشروع إلى مستشار محفظة للبورصة المصرية فقط. لا تحتوي على
تكامل مع وسيط، ولا تُنشئ أوامر تنفيذ، وكل مخرجاتها بحثية قابلة للمراجعة.

## السياسة الافتراضية

- رأس المال الابتدائي: 10,000 جنيه
- المساهمة الشهرية: 1,000 جنيه
- الأفق: من 3 إلى 12 شهرًا
- الحد الأقصى المقبول للتراجع: 20%
- 4 إلى 5 أسهم
- سيولة مستهدفة من 10% إلى 20%
- حد أقصى 25% للسهم و40% للقطاع
- الأولوية لعضوية مؤشر EGX الشرعي الموثقة رسميًا، ثم المراجعة المستقلة
  الموثقة محليًا ببصمة رقمية
- لا شراء عند نقص الأدلة؛ ولا بيع لمركز قائم اعتمادًا على بيانات قديمة

هذه حدود للمخاطر وليست ضمانًا لعدم تجاوز التراجع في السوق الفعلي.

## المصادر المقبولة

| المفتاح | الجهة | أقصى عمر |
|---|---|---:|
| `egx_prices` | البورصة المصرية | 7 أيام |
| `egx_disclosures` | البورصة المصرية | 30 يومًا |
| `egx_financial_statements` | البورصة المصرية | 220 يومًا |
| `egx_sharia_constituents` | البورصة المصرية أو الرقابة المالية | 220 يومًا |
| `cbe_macro` | البنك المركزي المصري | 90 يومًا |
| `capmas_inflation` | الجهاز المركزي للتعبئة العامة والإحصاء | 90 يومًا |
| `fra_rules` | الهيئة العامة للرقابة المالية | 365 يومًا |

يُتحقق من اسم النطاق كاملًا قبل الاتصال. لا يُقبل مثلًا
`egx.com.eg.attacker.example`. التحويلات الشبكية التلقائية معطلة، والاستجابة
محدودة الحجم ويجب أن تكون JSON. عند تعذر الموقع يمكن استيراد نسخة موثقة،
ويحفظ النظام SHA-256 ومتى نُشرت ومتى أصبحت معروفة له.

## التشغيل

بعد تثبيت المشروع:

```bash
pip install -e .
egx-portfolio --help
```

اطبع مخطط JSON الكامل لملف المحفظة:

```bash
egx-portfolio snapshot-schema > portfolio-snapshot.schema.json
```

استورد حزمة دليل محفوظة:

```bash
egx-portfolio import-evidence evidence-bundle.json \
  --database egx-evidence.sqlite3 \
  --expected-source egx_sharia_constituents
```

أنشئ الخطة:

```bash
egx-portfolio plan portfolio-snapshot.json --output egx-output
```

يخرج الأمر ملفين:

- `portfolio_plan.json`: نتيجة منظمة قابلة للاختبار والمعالجة
- `portfolio_plan.md`: تقرير عربي للمراجعة البشرية

لا يستبدل الأمر تقريرًا موجودًا إلا مع `--force`.

## رموز الخروج

| الرمز | المعنى |
|---:|---|
| 0 | أُنشئت خطة مستوفية للحواجز |
| 1 | خطأ في الإدخال أو الحفظ |
| 2 | حُفظ تقرير، لكن التوصية محجوبة بسبب نقص أو عدم صلاحية الأدلة |

## صيغة حزمة الدليل

```json
{
  "schema_version": 1,
  "source_key": "egx_sharia_constituents",
  "source_url": "https://beta.egx.com.eg/ar",
  "published_on": "2026-09-01",
  "observed_at": "2026-09-02T09:00:00+00:00",
  "authority": "official",
  "subjects": ["EFID.CA", "SWDY.CA"],
  "payload": {
    "tickers": ["EFID.CA", "SWDY.CA"]
  }
}
```

الوقت `observed_at` يجب أن يحتوي على منطقة زمنية ويُحوّل إلى UTC. الحقول
الإضافية غير المعروفة مرفوضة في حزمة الدليل.

## بوابة الجاهزية

طبقة الجلب العامة ومسار الاستيراد موجودان، لكن
`egypt_data_adapters_ready` يظل `false` عمدًا إلى أن تُحدد وتُختبر نقاط
النهاية الرسمية الفعلية لكل مصدر وتُراجع شروط استخدامها. لذلك لا ينبغي وصف
النسخة الحالية بأنها خدمة إنتاجية ذات تغذية حية، حتى لو كان محرك القرار
وحواجزه قابلين للاستخدام مع ملفات بيانات موثقة.
